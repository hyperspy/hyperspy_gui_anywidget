# Code of Conduct

This project is part of the HyperSpy ecosystem. We expect contributors and maintainers to collaborate respectfully, assume good intent, and make the project welcoming to people with different backgrounds and levels of experience.

## Expected behavior

- Be respectful in reviews, issues, discussions, and pull requests.
- Focus criticism on ideas, code, and behavior rather than people.
- Be thoughtful when giving feedback, especially to new contributors.
- Help keep technical discussions constructive and evidence-based.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Sexualized language or unwelcome conduct.
- Trolling, sustained disruption, or hostile review behavior.
- Publishing private information without consent.

## Reporting

If you experience or witness unacceptable behavior, please contact the project maintainers through the HyperSpy GitHub organization channels so the situation can be reviewed and handled appropriately.

Project maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that do not align with this Code of Conduct.
